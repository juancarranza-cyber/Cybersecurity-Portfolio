### 📡 01 — Nmap Network Scan Analysis

**Category:** Network Security / Reconnaissance Detection

Analysis of network reconnaissance activity using **Nmap and Wireshark** inside an isolated virtual cybersecurity laboratory.

The investigation focuses on identifying TCP connection attempts, analyzing packet behavior, reviewing TCP flags, and understanding how network scanning activity can be detected from a defensive perspective.

**Technologies**

`Nmap` `Wireshark` `Kali Linux` `Windows` `TCP/IP` `VirtualBox`

**Skills demonstrated**

* Network reconnaissance analysis
* TCP traffic analysis
* Packet inspection
* Port scanning analysis
* TCP flag analysis
* Reconnaissance detection
* Network monitoring
