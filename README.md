## 📡 01 — Nmap Network Scan Analysis

**Category:** Network Security / Reconnaissance Detection

Analysis of network reconnaissance activity using **Nmap and Wireshark** inside an isolated virtual lab.

### Technologies

* Reconnaissance detection
